### My Products

- **[lokii](https://github.com/huangy7/lokii)** — Blazingly fast, native macOS file search tool powered by Rust and AppKit. Everything-like instant indexing and search for Mac.
- **[MeowOut](https://github.com/huangy7/MeowOut)** — Native macOS menu bar toolkit with a pixel pet that keeps you healthy. Clipboard, 2FA, dropzone, memos, snippets, and live system monitor — in one app.
- **[seshbuddy](https://github.com/huangy7/seshbuddy)** — Desktop companion and session explorer for AI coding agents (Claude Code, Codex, Gemini, Antigravity, WorkBuddy, and more).
- **[outline-skill](https://github.com/huangy7/outline-skill)** — Open-source Agent Skill and CLI tool for managing and formatting documentation in Outline knowledge base.
- **[FlipBar](https://github.com/huangy7/FlipBar)** — Lightweight macOS menu bar utility for quick system toggles like hiding desktop icons, keeping Mac awake, and keyboard cleaning mode.
